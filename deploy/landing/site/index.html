Démo publique

▣ ParcelFlow

Plateforme d'expédition de colis en microservices .NET 8 : création d'envois avec devis et étiquette, paiement, entreposage, tournées de livraison, suivi public, facturation et notifications. Trois portails Angular passent par une API gateway authentifiée par Keycloak.

Les portails

Client

Portail client

Créer un envoi avec devis instantané, télécharger l'étiquette PDF, régler la facture, suivre ses colis et ses notifications.

Compte : emma.martin

Le mot de passe, commun à tous les comptes, est affiché sur la page de connexion de chaque portail.

Scénario conseillé

  1. Client : connectez-vous avec emma.martin, créez un envoi (le devis s'affiche en direct), puis réglez sa facture dans les 30 minutes.
  2. Entrepôt : sur le portail opérations, avec chloe.leroy, scannez le colis en entrée d'entrepôt, puis créez une tournée, affectez-lui un livreur et ajoutez le colis.
  3. Livraison : démarrer la tournée et livrer sont réservés au livreur affecté ou à l'administrateur. Reconnectez-vous au portail opérations avec admin.parcelflow, démarrez la tournée et confirmez la livraison.
  4. Suivi : revenez sur le portail client et consultez l'historique de suivi du colis (rechargez la page pour voir les nouvelles étapes).
  5. Administration : avec admin.parcelflow, consultez la facture de l'envoi (émise dès sa création), émettez si besoin un avoir, et suivez les indicateurs.

Suivi public sans connexion, sur un colis de démonstration en transit : PF400000000000000000000001 (JSON)

Sous le capot

8 services .NET 8

Customer, Shipment, Tracking, Warehouse, Delivery, Billing, Notification, Reporting. Une base PostgreSQL par service.

Messagerie

RabbitMQ et MassTransit, saga de réservation et délai de paiement côté Shipment.

Gateway

ASP.NET Core et YARP, validation JWT avec une audience par service, limitation de débit par IP et par utilisateur.

Identité

Keycloak, realm parcelflow, code + PKCE pour les portails, client_credentials pour l'appel de Notification vers Shipment.

Frontends

Trois portails Angular servis par nginx, même origine que l'API (/api/).

Hébergement

Docker Compose déployé par Dokploy derrière Traefik et Cloudflare. Images publiées par la CI GitHub Actions.

API : api.__DEMO_DOMAIN__ · Identité : auth.__DEMO_DOMAIN__

À savoir

  • Les comptes sont partagés entre tous les visiteurs : n'y saisissez aucune donnée réelle.
  • La démo est remise à zéro chaque nuit (vers 3 h, heure de Paris).
  • Les paiements sont simulés : aucune carte n'est demandée ni débitée, vous choisissez seulement si le paiement est accepté ou refusé.
