Démo publique

▣ ParcelFlow

Plateforme d'expédition de colis en microservices .NET 8 : création d'envois avec devis et étiquette, paiement, entreposage, tournées de livraison, suivi public, facturation et notifications. Trois portails Angular passent par une API gateway authentifiée par Keycloak.

Les portails

Client

Portail client

Créer un envoi, obtenir un devis, payer, télécharger l'étiquette et suivre ses colis.

Compte : emma.martin

app.__DEMO_DOMAIN__ → Opérateur

Portail opérations

Scans d'entrée et de sortie en entrepôt, stock des centres de tri, tournées de livraison.

Compte : chloe.leroy

ops.__DEMO_DOMAIN__ → Administrateur

Portail administration

Entreprises, tarifs, factures et avoirs, indicateurs de l'activité.

Compte : admin.parcelflow

admin.__DEMO_DOMAIN__ →

Le mot de passe, commun à tous les comptes, est affiché sur la page de connexion de chaque portail.

Scénario conseillé

  1. Client : connectez-vous avec emma.martin, créez un envoi, acceptez le devis et payez.
  2. Opérations : avec chloe.leroy, faites entrer le colis en entrepôt puis lancez la livraison.
  3. Suivi : revenez sur le portail client et suivez l'historique du colis en temps réel.
  4. Administration : avec admin.parcelflow, consultez la facture générée et les indicateurs.

Suivi public sans connexion, sur un colis de démonstration : PF400000000000000000000001

Sous le capot

8 services .NET 8

Customer, Shipment, Tracking, Warehouse, Delivery, Billing, Notification, Reporting. Une base PostgreSQL par service.

Messagerie

RabbitMQ et MassTransit, saga de réservation et délai de paiement côté Shipment.

Gateway

ASP.NET Core et YARP, validation JWT avec une audience par service, quotas.

Identité

Keycloak, realm parcelflow, code + PKCE pour les portails, client_credentials entre services.

Frontends

Trois portails Angular servis par nginx, même origine que l'API (/api/).

Hébergement

Docker Compose déployé par Dokploy derrière Traefik et Cloudflare. Images publiées par la CI GitHub Actions.

API : api.__DEMO_DOMAIN__ · Identité : auth.__DEMO_DOMAIN__

À savoir

  • Les comptes sont partagés entre tous les visiteurs : n'y saisissez aucune donnée réelle.
  • La démo est remise à zéro chaque nuit (vers 3 h, heure de Paris).
  • Les paiements sont simulés : aucune carte n'est demandée ni débitée.
